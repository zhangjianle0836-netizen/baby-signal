# 灵动岛与锁屏实时活动

## 范围

新增 WidgetKit 扩展 `BabySignalLiveActivity`，由 iPhone App 使用本地 ActivityKit API 请求、更新和结束。不需要推送服务、付费依赖或独立手表 App。扩展与 App 使用相同的 `MonitoringActivityState` 编码结构。

状态与真实监测关联：准备 → 有效分析后的监测；连续检测到哭声 → 哭声提醒；中断／恢复尝试 → 中断；有效分析恢复或已结束哭声提醒且分析正常 → 继续监测。停止监测立即结束活动。新进程启动时结束旧活动，因为旧音频会话已不存在，不假装接续监测。

系统允许前台创建、本地后台更新和结束。关闭实时活动权限、用户手动移除、达到时限或请求失败均不改变音频监测流程。权限关闭／创建失败提示在主页可见。

## 过期与时长

最近分析结果 + 30 秒设置 `staleDate`，扩展读取 `context.isStale`，过期后显示检查提示，并隐藏计时数字。更新约每 10 秒一次，状态变化即刻提交；更新任务按顺序执行，避免结束与创建互相覆盖。

单次活动最长 8 小时；7 小时 55 分钟先让显示过期。前台超过 7.5 小时刷新活动寿命，后台到期需打开 App 后重新显示。用户手动移除本次活动则尊重移除，不强制再创建。原监测会话起点保留，恢复音频引擎使用独立起点计算分析超时，避免将会话时长误当作音频重启等待时间。

## 验证记录

- 核心及真实静音分类器：67 项检查通过，包括过期边界、系统过期覆盖、显示寿命到期、哭声／恢复／中断文案和 App／扩展编码往返；5 个真实静音分析窗口。
- 双 target 真机签名构建通过，扩展已嵌入并安装到 iPhone 14 Pro（iOS 27.0.1）。构建有已签名调试扩展跳过再次 strip 的工具链警告。
- 真机实际显示：用户开始后，在桌面实际看到暖色警示图标和“已中断”；打开 App 后也显示“现在无法检测哭声”，两处状态一致。CPU 新版的正常监测收起状态已在桌面查看，锁屏恢复卡片由用户确认；展开界面尚未完成真机检查。
- 旧识别器那一轮出现后台中断；CPU 新版随后在停止系统提醒后收到有效分析，用户确认锁屏卡片显示“已恢复，继续监测中”。不能据一轮验证宣称整夜稳定。
- 尚未验证：完整 8 小时运行、用户移除后再次启动、关闭权限、VoiceOver 及哭声闹钟之后的所有恢复组合。
