# 隐私与公开资料

**简体中文** · [English](privacy.en.md)

## App 当前的数据处理

麦克风声音在手机本地分析，不写入音频文件、不上传。App 不包含服务器、广告或遥测服务。

本机保存最近 100 条事件（时间、类型、说明、闹钟状态、用户确认时间）、灵敏度、最近 60 条生命周期／系统错误诊断和最新恢复快照。这些时间与错误信息也可能揭示使用习惯，不应直接公开。

系统的签名、权限、闹钟、活动及通知由 Apple 平台处理；本项目不声称控制操作系统自身的数据处理。当前没有云同步或独立 Watch App。

## 仓库发布原则

仓库仅发布源码、工程、匿名文档、公开许可的模型资料与虚构 AI 插画。不发布原始视频／评论截图、真实当事人的身份、聊天、健康或家庭信息，不发布设备容器、测试录音、证书、Apple 账号、设备标识或个人签名配置。

`Config/Signing.local.xcconfig`、`.build/`、Xcode 用户配置、音频、证书和日志被忽略。忽略规则不能保证你以后新增的所有资料都安全；提交前仍应查看差异和提交文件列表。

GitHub 账号、公开仓库作者和贡献记录是开源发布本身的公开信息。本仓库使用 GitHub noreply 邮件提交，不使用私人邮箱。匿名故事不表示取得原视频当事人的授权或完成用户研究。

## 反馈

请用匿名步骤、设备型号／系统版本和最少的清理后错误码反馈，不上传真实宝宝的照片、声音或健康资料。确认你有权使用任何新增数据和素材。
