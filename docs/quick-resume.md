# 内置声音识别与快速恢复

## 当前选择

用户明确要求切回 Apple 内置声音识别器。当前 AudioMonitor 使用 `SNClassifySoundRequest(.version1)` / `baby_crying`。三档阈值恢复为 0.45 / 0.65 / 0.80，不沿用 YAMNet 分值。YAMNet 源码和模型保留作历史对比，不编译或嵌入当前 App，常规验证也不再要求编译 CPU 模型。

此设备内置识别器有已知锁屏中断问题。此更新提供恢复交互，不声称修复系统识别器的后台问题；不会用旧的 CPU 版恢复成功证明当前内置版稳定。

## 操作流程

1. 系统提醒响起，妈妈在系统界面停止闹钟；保留自动恢复逻辑。
2. 若未恢复，手机首页底部出现大按钮“快速恢复监测”。点一次重新连接麦克风、重置本轮有限重试机会，不需要先结束整个监测会话。
3. 中断／过期的锁屏卡片点击可打开 App 请求恢复，灵动岛展开显示“恢复监测”。健康状态仍显示“打开 App”。链接只调用本 App 的恢复入口，无网络请求。
4. 等收到有效分析结果，状态才变为继续监测；连接／等待期间显示中断或恢复中。
5. App 里的哭声确认按钮为“我去看看，并继续监测”，结束本次提醒并在仍有用户监测意图时触发恢复。此前手动停止后只确认旧记录不会启用录音。

权限关闭需重新授权；仍有响铃的系统闹钟时不抢占，提示先停止提醒。冷启动点击恢复链接是用户主动请求，可以重新开始，而普通 App 启动不会自动打开麦克风。

## 验证

65 项检查通过，包括快速重试保留用户意图、等待音频释放、有效分析确认恢复、显式停止不被晚到回调覆盖和真实内置分类器静音分析（5 个窗口）。双 target 真机签名构建通过并安装。用户本轮报告仍中断或未见按钮；设备快照证实锁屏三次重试失败。返回 App 前台后确实恢复有效分析（phase=monitoring、requested=true、attempts=0）。界面观察发现恢复中隐藏按钮但仍提示点击，已修复为同一位置显示禁用的“正在恢复，请稍等”，避免重复重启。最后补丁已构建安装，最终按钮点击及锁屏链接端到端操作仍待用户复核。更新重新启动后未自动开始监听，不播放测试声。
