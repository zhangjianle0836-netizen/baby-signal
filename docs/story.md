# 为什么做宝宝信号

发起人刷到一段关于听障妈妈照顾孩子的视频。评论中的一个观察让他停下来：当照护人听不到哭声时，可能需要一直或更频繁地看着宝宝。

日常生活里，许多提醒通过声音传递。宝宝哭了、有人按门铃、设备发出提示，能够听见的人可以转头去处理。听障照护人同样需要及时获得这些信息，提醒方式应当适合他们。

于是有了一个很朴素的想法：让手机在宝宝附近听取声音，发现候选哭声后，通过手表的触感和手机上的图片、文字提醒妈妈。妈妈收到信息后亲自查看宝宝，结束这一次提醒，监测继续运行；如果监测中断，界面告诉她真实状态并提供快速恢复入口。

这个项目从 iPhone 和 Apple Watch 做起，因为它们是最初测试已有的设备，并非假设所有家庭都负担得起苹果设备。长期希望不同开发者可以改造成更低成本的手机、手环或其他辅助提醒形式。

## 为什么把不完善的版本也公开

测试过程中，我们遇到了真正影响使用的问题：内置识别器在某台设备上锁屏后失败；换成 CPU 模型后后台流程可以运行，但现有短哭声没有触发连续确认。手表的系统测试闹钟曾成功震动，也不能证明睡觉时一定能叫醒使用者。

这些结果不应该藏在一个温馨的界面后面。将代码、状态设计、失败证据和验证方法一起开放，其他人才能判断适合做什么、还缺什么，以及从哪里改进。

我们期待的是可理解、可修改、可复核的工程起点。它尚不是经过可靠性验证的夜间照护工具。贡献者不应把调试、漏报或后台限制的风险转交给妈妈和宝宝。

## 公开故事怎样保护当事人

本故事只是对公开视频与评论启发的概括，未独立核实当事人的家庭或健康情况，也没有与当事人建立合作。公开资料不使用截图中的真实头像、昵称、位置、聊天记录、病情及其他可识别线索，不逐字复制私人对话或评论。
