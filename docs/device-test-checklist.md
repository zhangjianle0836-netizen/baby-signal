以下均为待测项。编译通过和模型处理静音输入，不等于家庭环境监测可靠或能唤醒使用者。

2026-10-14 进展：已签名安装并启动。用户确认手表自身计时器和 iPhone 自带计时器转发均能震动；本 App 的首轮 3 秒测试未收到手表震动。改为约 15 秒测试并立即锁屏后，用户确认一轮手表震动成功。下列涉及重复性、设置变化、哭声触发、整夜运行等验收项仍待逐项验证。

## 单独的提醒链路

先在宝宝休息区域外测试。手机可能发声。

- [ ] 点击测试，锁屏，记录手机／手表的实际提醒表现和延迟。
- [ ] 开启睡眠专注、勿扰、手机静音后分别测试。
- [ ] 手机亮屏解锁时测试，并与锁屏状态比较。
- [ ] 手表锁定、摘下、充电时分别测试；记录无法提醒的情况。
- [ ] 手表停止系统闹钟，手机记录显示系统结束，不能自动显示用户确认。
- [ ] 手机手动确认感知，记录单独保存确认时间。
- [ ] 从记录取消尚未触发的闹钟，确认不会继续提醒。
- [ ] 重启 App 后，仍可查看和取消尚未结束的闹钟。
- [ ] 同房、隔墙、远离手机以及断网／断连情况下分别测试。
- [ ] 记录是否有不希望出现的手机声音；不能只观察屏幕通知。

## 声音检测

可先用合法持有的哭声录音做工程测试；播放录音不替代真实家庭观察。不要让宝宝为了测试持续哭泣。

- [ ] 数段短哭、轻哭、间歇哭与持续哭，分别记录漏报和延迟。
- [ ] 电视／手机播放的哭声、成人哭声、猫叫、说话、风扇、白噪音，分别记录误报。
- [ ] 手机不同距离、朝向与摆放位置的识别情况。
- [ ] 三档灵敏度分别测量，避免根据少量样本宣称准确率。
- [ ] 确认连续哭声不堆叠多个闹钟，停止闹钟后持续哭声可以再次提醒。
- [ ] 确认约 10 秒低置信度间隔后的新哭声事件可以提醒。
- [ ] 长时间保持安静仍收到分析结果，不出现误报。

## 后台与恢复

先保持连接调试观察日志，再脱离调试器复测。最终不能仅依赖调试器连接时的行为。

- [ ] 手机锁屏后仍分析，锁屏期间真实声音能触发提醒。
- [ ] 电话、FaceTime、Siri、闹钟分别打断时，记录暂停／恢复状态。
- [ ] 由本 App 的闹钟触发后，麦克风是否被中断；停止闹钟后能否继续检测下一次事件。
- [ ] 耳机接入／拔出时停止并提示，不悄悄更换为远离宝宝的麦克风。
- [ ] 用户停止监测后不会因为迟到的音频结果生成新事件。
- [ ] 快速开始／停止，权限弹窗尚未结束就停止，不意外恢复监听。
- [ ] 强制退出／手机重启后，界面不显示此前仍在监测，需用户重新开始。
- [ ] 运行数小时，记录手机耗电、温度、分析停止和手表电量变化。

## 夜间与无障碍

测试期间保留原有照护安排，白天感知成功不等于睡眠唤醒成功。

- [ ] 使用者在自然睡眠中的感知与醒来情况，记录多次测试结果。
- [ ] 大字体、深色模式、横屏时内容可滚动，按钮和状态不被裁切。
- [ ] VoiceOver 可以读出按钮、权限、监测状态和记录，不依赖颜色或声音。
- [ ] “取消闹钟”“停止监测”“确认感知”三种操作能被使用者正确理解。

## 记录格式

每个样本记录：设备版本／设置、场景、真实哭声开始时间、手机事件时间、手表感知时间、是否醒来、停止操作、监听是否恢复。

分别计算：事件漏报、每小时／每晚误报、端到端提醒延迟、感知／唤醒比例和中断后恢复情况。当前没有经过验证的目标值，不能把预设阈值当作质量证明。
