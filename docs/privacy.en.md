# Privacy and public materials

[简体中文](privacy.md) · **English**

## Current app behavior

Microphone audio is analyzed locally, not written to audio files or uploaded. The app contains no server, advertising or telemetry service.

The phone stores up to 100 events (time, type, description, alarm state and user receipt time), sensitivity, up to 60 lifecycle/system-error diagnostics and a recovery snapshot. These may reveal usage patterns and should not be published unedited.

Apple handles system signing, permissions, alarms, activities and notification behavior. We do not claim control over operating-system data handling. There is no cloud sync or independent Watch app.

## Repository policy

Publish source, project files, anonymous documentation, licensed model materials and fictional AI art. Exclude original video/comment screenshots, real identities, chats, health/family details, device containers, audio, credentials, identifiers and private signing.

`.build`, `Config/Signing.local.xcconfig`, Xcode user state, audio, certificates and logs are ignored. Review changes before committing; ignore rules do not make every future addition safe.

The publishing GitHub account, authorship and contribution history are public by design. Commits use a GitHub noreply address. An anonymous story does not imply original-person consent, collaboration or completed user research.

Use anonymous steps and minimal sanitized diagnostics for feedback. Make sure you have the right to use any data or assets you add.
